# Временная ссылка BTBS

Скрипты запуска сохранены в UTF-8 с BOM для совместимости с Windows PowerShell 5.1 и PowerShell 7. В VS Code при их редактировании сохраняйте кодировку **UTF-8 with BOM**, чтобы русские строки не приводили к ошибкам разбора.

Запуск из PowerShell в папке LMS:

```powershell
.\Start-LMS-Share.ps1
```

Скрипт собирает интерфейс, запускает отдельный сервер демонстрации и Cloudflare Quick Tunnel. Готовая ссылка показывается в терминале и сохраняется в `.local/temporary-link.txt`. Повторный запуск проверяет доступность внешнего API: работающая ссылка сохраняется, недоступный туннель запускается заново. Регистрация нового адреса может занять до 50 секунд. После остановки и нового запуска адрес изменится.

Отправьте HTTPS-ссылку посетителю. Он может открыть её с телефона или компьютера через любую сеть. Для работы нужны включённый компьютер, работающие сервер и туннель, интернет и запущенная PostgreSQL. У пользователя будет отдельная сессия входа; действуют существующие аккаунты и роли LMS. Регистрация создаёт ученика.

Отключить доступ:

```powershell
.\Stop-LMS-Share.ps1
```

Остановка выключает только временную демонстрацию. Локальный адрес `http://127.0.0.1:5173` работает отдельно. Не закрывайте фоновые процессы, пока показываете проект.

Внешний запуск использует собранный `frontend/dist`, Waitress и отдельные настройки Django с `DEBUG=False`, точным списком допустимых доменов, HTTPS cookies и проверкой CSRF. Исходники и `.env` не раздаются. База и материалы — те же, что в локальном проекте, поэтому действия вошедших пользователей сохраняются.

Дополнительные зависимости: `backend/requirements-share.txt`. Cloudflared загружается из официального репозитория Cloudflare, перед запуском сверяется SHA256 с метаданными релиза. Роутер и брандмауэр не перенастраиваются: соединение туннеля исходящее, отдельный сервер слушает только `127.0.0.1`.

Это временная демонстрация. Quick Tunnel не обещает постоянную доступность: [официальная документация Cloudflare](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
