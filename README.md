# LMS Academy

React + TypeScript + Vite, Django 5.2, PostgreSQL. Основная версия проекта находится в этой папке.

Обновление с модулями, шагами, группами, общением, уведомлениями и проверкой Python: [PLATFORM_V2.md](PLATFORM_V2.md). Ниже сохранена инструкция первого учебного цикла; актуальные команды подготовки и расширенный демо-сценарий приведены в новом документе.

## Запуск на Windows

В PowerShell из папки LMS:

```powershell
.\Start-LMS.ps1
```

Открыть http://127.0.0.1:5173. Серверы слушают только локальный адрес. Скрипт не перезапускает уже занятые порты. Логи находятся в `.local/`.

Для разработки с автоматической перезагрузкой можно запустить в двух терминалах:

```powershell
cd backend
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

```powershell
cd frontend
npm.cmd run dev -- --host 127.0.0.1
```

Параметры PostgreSQL и секретный ключ находятся в `backend/.env`. Образец — `backend/.env.example`.

## Что проверить

Демо-аккаунты и случайные пароли сохранены локально в `.local/demo-access.json`. Они созданы отдельно от существующих пользователей. При необходимости создать демо заново в новой базе: `python manage.py seed_demo` (только DEBUG).

1. Войти преподавателем → «Кабинет преподавателя» → «Управлять обучением» у демо-курса.
2. Создать, изменить и опубликовать урок. Загрузить материал. Снять с публикации или удалить ненужный урок/материал.
3. Во вкладке «Задания» создать задание со сроком, шкалой баллов и числом попыток.
4. Войти студентом → открыть демо-курс → отправить текст или файл ответа.
5. Войти преподавателем → «Задания» → раскрыть работу → выставить оценку и комментарий. Посмотреть «Журнал».
6. Студент увидит оценку и комментарий в задании и лучший балл в «Мои результаты».
7. В «Тесты» пройти тест. Выбранные ответы сохраняются на сервере. Перезагрузка позволяет продолжить ту же попытку; таймер продолжает идти.
8. Отметить уроки пройденными и проверить прогресс.

## Правила

- Курсы, уроки, задания и тесты публикуются отдельно. Черновики доступны управляющему курсом.
- Студенту нужны опубликованный курс и запись на него. Чужие работы и оценки недоступны.
- Ответ на задание: текст и/или PDF, DOCX, PPTX, JPG, PNG до 20 МБ. У учебных материалов дополнительно поддерживаются DOC/PPT и MP4/WEBM (видео до 100 МБ).
- После срока сдача задания запрещена. После появления работ нельзя менять шкалу и лимит попыток или удалять задание; его можно скрыть.
- Тесты имеют один верный вариант на вопрос и один балл за ответ. Проверка, время и лимит попыток контролируются сервером. Просроченная попытка получает 0 баллов. Ответы, не отправленные до окончания времени, не засчитываются.
- После начала попыток содержание и расписание теста фиксируются; доступно снятие с публикации.
- Журнал показывает лучший проверенный результат по опубликованным заданиям и тестам. Прогресс учитывает опубликованные уроки и отметки студента.
- Удаление урока удаляет его материалы и отметки прогресса. Интерфейс запрашивает подтверждение.

## Проверки

```powershell
cd backend
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test accounts courses learning assessment --noinput
```

```powershell
cd frontend
npm.cmd run lint
npm.cmd run build
```

Тесты backend создают отдельную PostgreSQL базу `test_<DB_NAME>` и не очищают рабочие данные. Миграции новых таблиц: `python manage.py migrate`.
