# Проверка безопасности и просмотр файлов — 15 ноября 2026

## Изменения
- PDF, растровые изображения и видео учебных материалов показываются внутри урока; общая панель с разворачиванием и мобильной вёрсткой. Просмотр учебных материалов в режиме преподавателя использует ту же панель. Файлы собственных ответов ученика используют её также.
- Для Word/PowerPoint и прочих неподдерживаемых форматов есть скачивание без новой вкладки. Конвертация этих документов в PDF не реализована; сторонним сервисам документы не передаются.
- Встраиваются только собственные API-ссылки LMS. HTML/SVG не исполняются в просмотрщике. Локальные защищённые файлы разрешено встраивать только с того же сайта (SAMEORIGIN); проверки записи на курс и открытия модуля сохранены.
- Nginx ограничивает частоту входа, регистрации и запроса восстановления по IP: 5 запросов/секунду, burst 20, превышение 429. Это ограничение на входе Nginx, не постоянная блокировка учётной записи. Общий IP школы делит этот лимит.
- Закрыты URL со скрытыми файлами; admin и media остаются закрыты на Nginx. Секреты, локальные архивы и виртуальное окружение исключены из Docker-контекста.
- Подсчёт прогресса больше не читает попытки посторонних тестов: выбираются только тесты шагов курса и контрольные тесты запусков. Пустой набор исключает ненужный SQL-запрос. Реальный прирост p95 после этой правки ещё не измерен.

## Проверки
95 серверных тестов прошли: вход, права администраторов, S3/multipart, закрытые модули, дедлайны, прогресс, CSRF и доступ к PDF. Дополнительный прогон ответов учеников записан в .local/submission-security-check.log. Frontend build/lint прошли. Nginx configuration test прошёл.

На рабочем HTTP-сервере: /.env → 404; /media/private.pdf → 404; /admin/ → 404; материал без входа → 401. Из серии 45 запросов входа без CSRF: 23 отклонены с 403, ещё 22 ограничены с 429. Браузерная проверка встроенного видео и разворачивания: .local/material-viewer-proof.jpg.

## Пределы проверки
Это проверка основных сценариев и настроек, а не полный независимый аудит или сканирование всех зависимостей. Локальный Docker опубликован на 127.0.0.1:8080, поэтому secure cookies в нём выключены для HTTP. Перед постоянным внешним размещением нужны HTTPS и secure cookies. Подписанные CDN-ссылки действуют ограниченное время; получатель может передать действующую ссылку другому человеку.

Высокая задержка при 100 клиентах не считается полностью устранённой. Нужны отдельный генератор нагрузки и дальнейший профиль приложения/базы. Оптимизация не подменяет измерение.

Рабочие контейнеры обновлены; последние исходники и frontend dist применены также непосредственно. Последняя повторная сборка nginx не смогла обратиться к Docker Hub из-за DNS; предшествующий образ собран успешно. После восстановления доступа повторить docker compose -f deployment/compose.yaml build web nginx для включения всех последних правок в образы.
